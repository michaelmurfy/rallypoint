# Red Alert 2 / Yuri's Revenge community map packs

Classic Westwood-era multiplayer packs (`.mmx` / `.yro`) shipped with the launcher so players can install them
from the RA2 Maps page without hunting downloads. Each zip is pinned by SHA-256 in `../ra2-mappacks.json`.

They are community maps, not EA's official multimd set. Rallypoint does not claim ownership; you still need your
own legal copy of Red Alert 2 / Yuri's Revenge to play.
