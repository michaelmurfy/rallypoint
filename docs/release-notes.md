## Rallypoint 0.5.5

Multiplayer opens the LAN lobby directly, the game's window and Mac menu name the game, and the Play page fits without a scrollbar.

- **Multiplayer goes straight to the LAN lobby.** The Online and Network step is gone.
- **The window names the game.** The title shows the mod you are playing (or Zero Hour), not the engine fork.
- **A real Mac menu.** The menu bar shows the game's name with Hide and Quit (Cmd+Q), and the Dock shows the Zero Hour icon from your own game folder.
- **No more "MISSING: GUI:CustomMission".** The unused button in the Zero Hour menu is hidden.
- **Play page fits.** The resolution note is gone, so the page no longer scrolls at the default window size on Mac.
- **Debug logs dialog.** The replay switch keeps its shape and the label reads as normal text.
- **Credit.** The engine now builds from our own fork of dvcdsys's macOS port, and the README credits them.
- **Known on Mac.** Some parts (the base pad, flags, a few units such as the GLA worker) still draw black. This build adds diagnostics to find the cause.

## Rallypoint 0.5.4

The right art for every game on the Play card, no more Downloads folder prompts on Mac, and the version in the sidebar. Chaos and Cold War Crisis show their own artwork, and Rallypoint no longer looks in your Downloads folder when it starts.

## Rallypoint 0.5.3

Fixes a Mac and Windows desync in long games, makes lobby guests start with the host's cash, and gives the Play card the game's own artwork. A player's first battle plan no longer makes the two machines count their unit lists differently (older versions are refused at the lobby), a guest keeps the host's starting cash, and the Play card is blue for Zero Hour and red for the mods.
