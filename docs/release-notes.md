## Rallypoint 1.0.4

**Linux plays a lot better.** The game now behaves on multi-monitor desktops, shows its own mouse cursors and keeps the keyboard. Everyone in a room needs 1.0.4.

- **One monitor by default.** Fullscreen no longer stretches over every screen. Want surround? Tick **Span all monitors** in Settings > Graphics.
- **Mouse cursors.** The game's own cursors show on Linux instead of nothing.
- **Keyboard keeps up.** Switching windows no longer leaves the game without the keyboard or with Shift and Ctrl stuck down.
- **Double-click select.** Double-clicking a unit selects every unit of that type again.
- **Setup wizard.** Steam installs are listed once, and long folder paths wrap instead of running off the screen.
