## Rallypoint 0.7.1

**The command bar choice now lives where you look for it.** A small release that fixes a feature people could not find.

- **Command bar on the Mods page.** The Control Bar HD card has a **Command bar** dropdown: sharp icons or Control Bar Pro. The same choice is still in Settings > Graphics.

## Rallypoint 0.7.0

The first full 0.7 release: a 64-bit game engine on Windows, an Enhanced renderer with tunable looks, Control Bar Pro, a resolution picker and more starting money in the skirmish setup, and a game that no longer opens a remote control on your computer.

## Rallypoint 0.7.0-beta.4

A security fix (the game no longer opens a remote control on your machine), voices that play at their own speed again on 64-bit Windows, and a keyboard that keeps working in macOS fullscreen.
