## Rallypoint 0.5.9

Every game's maps in one list, each with a tag saying where it comes from.

- **All official maps, not just one game's.** The Maps page used to show only the maps of the game picked on the Play page. It now lists Zero Hour, Shockwave, Shockwave Chaos and Cold War Crisis maps together (for the games you have installed).
- **Tags.** Each map has a green **Official** tag and one for its game. A map two games both ship shows both.
- **Skirmish picks the right game.** Setting up a skirmish on an official map switches "Play with" to the game that has it, so it starts without a trip to the Play page.

## Rallypoint 0.5.8

The game's own maps joined the map list, marked **Official**: Zero Hour's (plus the original Generals maps) or a mod's own. Only skirmish maps are listed, they can't be switched off or deleted, and a map of yours with the same name wins.

## Rallypoint 0.5.7

Skirmishes got a speed menu (50% to 200%, never online), the README gained a proper server setup guide with an Ansible playbook and a `rallypoint` helper, `make up` waits for the container to be healthy, and Settings has a Changelog button.
